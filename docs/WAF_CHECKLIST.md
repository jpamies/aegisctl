# WAF Checklist

> Per-pillar checklist aligned to the **Azure Well-Architected Framework (WAF)**.
> This checklist is generated by Aegis and reflects the state of the analysed
> repository at the time of the scan.

**Note:** WAF here refers to the **Well-Architected Framework**, not Web
Application Firewall.

---

## How to use this checklist

- **✅ Pass** — The repository or architecture meets this criterion.
- **⚠️ Partial** — Some evidence found but incomplete.
- **❌ Fail** — Not detected or not implemented.
- **N/A** — Not applicable to this workload.

Status values are populated by `aegisctl pack` or `aegisctl score`. In this
template, all items default to `TODO:` for manual review.
